# 电商运营AI助手 - SaaS平台

## 项目简介

一款面向中小电商卖家的AI运营工具SaaS平台，集成商品标题生成、详情页文案生成、客服话术生成、店铺运营诊断四大核心功能，帮助电商卖家提升运营效率和转化率。

## 核心功能

### 1. 商品标题生成
- 输入商品名称、类目、卖点，AI自动生成5个高点击率标题
- 支持淘宝/拼多多/抖音/京东/快手多平台
- 符合平台标题规则，避免违规词

### 2. 详情页文案生成
- 一键生成完整详情页文案，包含卖点、参数、尺码、场景、售后等模块
- 针对目标用户定制文案风格
- 提升转化率，减少详情页制作时间

### 3. 客服话术生成
- 生成售前售中售后全场景客服话术库
- 支持亲切热情/专业严谨/活泼可爱/简洁高效多种风格
- 覆盖10+常见问题，提升客服响应速度和转化率

### 4. 店铺运营诊断
- 输入店铺核心数据，AI生成完整运营诊断报告
- 从流量、转化、客单价、爆款、内容、活动多维度分析
- 给出具体可执行的优化建议和本周行动计划

## 技术栈

- **后端**：Python Flask
- **前端**：HTML + CSS + JavaScript（原生，无框架依赖）
- **AI接口**：豆包大模型API（兼容OpenAI格式）
- **部署**：支持本地运行、云服务器部署、Docker部署

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置API密钥（可选）

不配置API密钥时，系统自动进入**演示模式**，返回示例数据，可用于体验界面和功能流程。

配置真实AI生成能力：

**方式一：环境变量**
```bash
# Windows
set DOUBAO_API_KEY=你的API密钥
set DOUBAO_MODEL_ID=你的模型ID

# Linux/Mac
export DOUBAO_API_KEY=你的API密钥
export DOUBAO_MODEL_ID=你的模型ID
```

**方式二：直接修改代码**
编辑 `app.py`，修改以下两行：
```python
API_KEY = "你的API密钥"
MODEL_ID = "你的模型ID"
```

**获取API密钥**：
- 访问火山引擎官网：https://www.volcengine.com/product/doubao
- 注册账号，开通豆包大模型服务
- 创建API Key，获取Endpoint ID（模型ID）

### 3. 启动服务

```bash
python app.py
```

### 4. 访问使用

打开浏览器访问：http://127.0.0.1:5000

## 部署上线

### 方式一：云服务器部署（推荐）

1. 购买云服务器（阿里云/腾讯云/华为云，最低配置1核2G即可）
2. 安装Python 3.8+
3. 上传项目代码到服务器
4. 安装依赖：`pip install -r requirements.txt`
5. 配置API密钥环境变量
6. 使用gunicorn启动：
   ```bash
   gunicorn -w 4 -b 0.0.0.0:5000 app:app
   ```
7. 配置Nginx反向代理，绑定域名
8. 配置SSL证书（HTTPS）

### 方式二：PythonAnywhere（免费/低成本）

1. 注册PythonAnywhere账号
2. 上传项目代码
3. 配置Web App，选择Flask
4. 配置API密钥
5. 绑定域名（可选）

### 方式三：Docker部署

```dockerfile
FROM python:3.9-slim
WORKDIR /app
COPY . .
RUN pip install -r requirements.txt
EXPOSE 5000
CMD ["gunicorn", "-w", "4", "-b", "0.0.0.0:5000", "app:app"]
```
